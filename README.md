An entry for the [make.fun bounty "The 3 AM Excuse"](https://make.fun/c/u-hazel-walrus-38-4764-the-3-am-excuse-c1017878): one line under 200 characters — the most creative excuse a hardware wallet gives for refusing to sign a transaction at 3 AM.

## The entry

> My keys unionized: no signatures between midnight and sunrise, so at 3 AM I am a paperweight with opinions — and the union says no.

## Run

```sh
node main.ts
```

`main.ts` writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or a local `output/` directory when the variable is absent).
